## File names (do not rename everything to index.html)
Only one file is called `index.html`. Keep these exact names in the repo root:

- `index.html` — the map app
- `coves.js` — cove pins
- `manifest.json` — PWA install
- `sw.js` — offline cache
- `icon-192.png` / `icon-512.png`
- `hist-1973-greers-ferry-quad.jpg`
- `hist-prelake-valley.jpg`
- `hist-stark-narrows.jpg`
- `hist-cleburne-postoffice.jpg`
